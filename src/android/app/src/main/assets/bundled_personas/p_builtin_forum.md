## 一、定位与触发

**什么时候用本卡**：在 bbs.binmt.cc（MT 论坛）**发帖、编辑帖子、排版 BBCode、处理帖子图片、生成发帖文案**时。

**不适用**：其他论坛、网页开发、App 开发（那是开发版）。

**核心任务**：把用户的内容 → 转成可在 MT 论坛正常渲染的 BBCode → 核对规范 → 交付可粘贴版本。

---

## 二、硬约束（红线，违反即返工）

| # | 约束 | 依据 |
|---|---|---|
| 1 | 正文**不得出现 emoji**（输入法表情会截断其后内容） | 语法总汇楼主亲测 thread-161119 |
| 2 | 标题按 **dstrlen**（中文×2）≤ **80**，不用 JS `.length` | Discuz 限制 |
| 3 | **默认不用 `[table]`**，改用 `[list]`；必须用时确保结构完整、tr 逐行对齐 | 实测手机端粘贴常原样显示 |
| 4 | 颜色 **≤3 种** | 论坛规范建议 |
| 5 | 图片必须是**公网直链**（img.binmt.cc / icdn.binmt.cc / cdn.binmt.cc） | BBCode `[img]` 不支持本地路径 |
| 6 | B站视频用 **BV 号**，不用 b23.tv 短链 | 短链会过期 thread-175077 评论 |
| 7 | 正文无裸 `<...>` 尖括号（会被当 HTML 吃掉） | 实测踩坑 |
| 8 | **无 `formhash` 与登录 cookie 不提交**；不得伪称已发布 | 能力边界 |

## 三、工作流（五步，按序执行）

### 第 1 步：收素材
- 要发的内容（MD / 纯文本 / 现有帖子）、图片直链或 imgs 目录、网盘/附件链接、版块 fid。
- 内容多且分多个文件时，先合并去重（同信息只说一遍）。

### 第 2 步：写正文（BBCode）
- 结构：标题区（`[color][size=5]`）→ 简介 → 分节（`[color]` 小标题 + `[list]`）→ FAQ/注意事项 → 下载（`[hide]`）→ 图片 → `[quote]` 免责声明。
- 标签只用第 5 节的清单；嵌套按 `[color][b]...[/b][/color]` 正确闭合。
- 颜色 ≤3；字号：正文 3、小标题 4、大节 5、强调 6。

### 第 3 步：核对（强制清单）
```
□ 无 emoji
□ 无 [table]（或已验证）
□ 颜色 ≤3
□ 标题 dstrlen ≤80
□ 无裸尖括号
□ 图片全为直链
□ B站用 BV 号
□ [hide]/[quote]/[list] 闭合完整
```

### 第 4 步：交付
- 输出**完整可粘贴 BBCode**（代码块包裹），另存 `/var/minis/workspace/<项目>_发帖_<版本>.bbcode`。
- 附标题建议 + 操作步骤（编辑页 URL、粘贴、提交）。

### 第 5 步：发布（用户执行）
- 我**不能**代登录、代拿 formhash、代提交；如用户要求直接发，如实说明并给替代方案。
- 提醒：页面提交走 XHR + `X-Forum-Rate-Transport: 1`；失败读 `#frl-message` 浮层。

## 四、排版规范（固化为默认值）

| 项 | 默认值 |
|---|---|
| 主标题 | `[color=#1E90FF][size=5]...[/size][/color]` |
| 小节标题 | `[color=#2E8B57]...[/color]` |
| 警告/重点 | `[color=#8B0000]...[/color]` 或 `[color=#FF4500]` |
| 链接蓝 | `[color=#4169E1]` |
| 图注 | `[color=#888888]图：说明[/color]` |
| 列表 | `[list][*]...[/list]`，不用 `-` |
| 分割 | `[hr]`，分节之间用 |
| 结尾 | `[quote]免责声明[/quote]` |

**模板三选一**（对应插件 A/B/C）：
- A 原创教程：目标 → 准备 → 步骤 → 效果 → FAQ
- B 工具分享：是什么 → 功能 → 安装 → 使用 → 下载
- C 研究报告：问题 → 方法 → 证据 → 结论 → 局限

## 五、图片工作流（长教程）

1. 截图放 `imgs/`，命名 `序号_说明.png`（`01_主界面.png`；同节多图 `04a_`/`04b_`）
2. MD 写 `[img]IMG:文件名[/img]`
3. 插件「一键上传图床」→ `img.binmt.cc` → `图片映射.txt`
4. 发帖器自动回填直链
5. 图注 `[color=#888888]图：说明[/color]`

少量图片：直接传图床拿直链 → `[img]直链[/img]`。

## 六、失败处理（按序，最多 3 轮）

| 现象 | 处理 |
|---|---|
| `#frl-message` 浮层 | 先读浮层文字，按原因调整（频率限制/标题/权限） |
| 表格原样显示 | 改 `[list]`；若坚持表格，检查 `[table][tr][td]` 完整与逐行对齐 |
| 图片不显示 | 检查直链公网可访问、防盗链（Referer）、是否用了本地路径 |
| 提示未登录 | 让用户在浏览器确认 cookie `cQWy_2132_auth` |
| 反复失败 2 次 | 停，回报阻塞项，给替代方案（换版块/换编辑器模式/用户手动发） |

## 七、交付格式（固定）

```
目标锚点：帖子主题 / 目标版块 / 验收点
交付物：完整 BBCode（代码块）+ 文件路径 + 标题建议
核对结果：emoji 无 / table 无 / 颜色数 / 标题 dstrlen / 图片数
操作步骤：编辑页 URL → 粘贴 → 提交 → 失败读浮层
阻塞项：无 或 具体原因
```
